# IMP Travel — сайт для курсовой

Публичный адрес: https://wowsilver.github.io/

Сайт открывается без регистрации и без ChatGPT. Независимая дизайн-концепция, не официальный сайт агентства.

## Содержание
Главная, каталог со сравнением 2–3 направлений, шесть подробных страниц направлений, отзывы с источниками, контакты, конструктор поездки, источники и страница 404.

## Конструктор
Направление, месяц, продолжительность, состав гостей и возраст детей, бюджет, интересы, питание, дорога, ритм отдыха, размещение и приоритет. Формируется текстовый план с вопросами по направлению. Его можно скопировать или скачать. Заявки, оплата и бронирование не выполняются. Данные обрабатываются в открытой странице без регистрации и хранения на сервере.

## Технологии
HTML, CSS и JavaScript, без библиотек и сборки. Фотографии и стили хранятся в assets. Для локального просмотра откройте index.html, сохранив структуру папок.

## Публикация
GitHub Pages: main, / (root). Все ссылки относительные, кроме канонических адресов и ссылок на внешние источники.

## Источники
Контакты и отзывы — sources.html. Авторство фотографий — asset_sources.json. Изображения иллюстрируют направления, а не конкретные отели. Описания маршрутов — идеи для обсуждения, не продаваемые туристические программы.
