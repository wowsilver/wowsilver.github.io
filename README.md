# IMP Travel — HTML-сайт для курсовой

Независимая концепция сайта туристического агентства. Проект не связан с официальным сайтом компании и не принимает персональные данные, заявки или платежи.

## Состав
Главная, направления, отзывы, контакты, конструктор плана поездки, источники и страница 404. HTML, CSS и JavaScript без сборки и внешних библиотек. Фотографии хранятся в assets.

## Открыть локально
Распакуйте архив и откройте index.html. Сохраняйте структуру папки assets.

## GitHub Pages
Загрузите содержимое архива в корень репозитория. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). В исходном проекте файлы сайта находятся в dist.

## Работа конструктора
Выбор направления, даты, состава поездки, возраста детей, бюджета и интересов. Готовый текст можно скачать. Отправка в агентство не выполняется. Копирование зависит от поддержки браузера; скачивание доступно отдельно.

## Материалы
Источники отзывов и контактов приведены на sources.html; авторы и страницы фотографий — в asset_sources.json. Не выдавайте этот проект за официальный сайт агентства.
